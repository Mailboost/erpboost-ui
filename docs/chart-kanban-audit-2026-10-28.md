# チャート・日程編集・カンバンの追加比較（2026-10-28）

参照: https://ui.tailor.tech/  
公開先: https://mailboost.github.io/erpboost-ui/

通知・承認・フォームの前回検証に続き、グラフのツールチップ、ガントの日程編集、カンバンの表示切替と移動後の状態を確認した。**ガントの日付入力に、参照では不正値を破棄するのにERPboostでは保存できる差分があり、修正した。カレンダーの月外の日付表示・配色・ポップアップ位置も合わせた。**

全操作・全画素の完全一致という判定ではない。今回の範囲は以下のとおり。

## 修正した差分

| 対象           | 修正前                                                                          | 修正後                                                                                             |
| -------------- | ------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| 実在しない日付 | `2026-02-31`などを親の予定データへ渡せた。描画・カレンダーでは3月へ繰り越される | 入力中の文字列と確定値を分離。存在しない日付や未完成の入力は、フォーカス移動時に最後の確定値へ戻す |
| うるう日・空白 | 実在日付を確認せず、そのまま保存                                                | `2026-02-29`は破棄、`2028-02-29`は保存。前後の空白を除去し、正しい日付だけを親へ渡す               |
| カレンダー     | 月外の日付がなく、矢印の塗り・月外の日付の濃さ・ポップアップ位置が異なる        | 参照と同じ月外の日付、矢印、当日表示、余白・衝突回避を適用                                         |

変更対象はガント用の`DatePickerField`。通常のDatePickerコンポーネントやデータ保存APIを変更したものではない。

不正日付を保持する現象を最初は参照側も同じと推測したが、参照の入力中表示と確定値が別であることを確認し、訂正した。参照の実際の画面と配信中の実装を照合し、blurで破棄されることを確認して修正した。

## 検証中の推測を取り消した点

カンバンの案件種類切替で折りたたみが消えるという差を途中で疑ったが、同じ操作条件にそろえて再確認すると参照・ローカルとも保持された。PCでポインター切替とキーボード切替を各3往復し、両サイトで同じ結果だった。途中で試したリマウントによる変更は取り下げ、カンバンのアプリコードは変更していない。

モバイルでは参照側にもヘッダの重なりがあり、案件種類タブがポインター操作で押しにくい。回帰テストではタブへフォーカスしてEnterで切り替える経路を検証した。ポインターの当たり判定を強制的に回避してクリック成功と数えてはいない。

## 参照側にも残る制約

- ガント内の編集ポップアップでは、周囲のチャートがキーイベントを処理してしまい、Backspaceや通常の文字入力が抑止される。両サイトでネイティブのキーイベントが`defaultPrevented`になることを確認した。**既知の問題を再現する1ケース／環境は、キーボード入力が正常に使える成功ケースではない。**
- 日付の入力検証ではPlaywrightの`fill`による入力値の置換とblurを使った。これは実際の連続キー入力が正常に使える証明ではない。カレンダーの日付選択は実ポインターで操作した。
- ガント・案件の変更はメモリ内だけで、再読込すると初期化される。サーバー永続化の成功ではない。
- `Create deal`、詳細の`Log activity` / `Move stage`はサンプルでは実処理を行わない。`Open full page`は`#`。作成APIや業務画面への遷移成功に数えない。
- グラフの値は固定のサンプル。凡例で系列を非表示にする処理や、期間・データの取得条件を変更する処理はない。

## 画像比較

積み上げ棒のQ2ツールチップ、3月のカレンダーを開いた状態、案件詳細をPC・モバイルで撮影した。フォントの読み込みとRechartsの初期アニメーション完了を待って比較する。

参照対ローカル・参照対公開版の計12比較では、積み上げ棒・案件詳細のPC／モバイルと、モバイルのカレンダーの計10比較は差分0画素だった。PCのカレンダーを含む画面全体の2比較には各823画素の差があり、差分領域はガントのDiscoveryラベルの内側／外側の配置。カレンダー自体の領域には差がなかった。既存記録にあるフォント読み込み順によるラベルの配置差として残す。

これは特定状態の撮影結果であり、グラフ全点・全サイズ・全アニメーションフレームの一致保証ではない。
