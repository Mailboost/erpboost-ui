# 表の右クリック・絞り込み・選択表示の追加検証（2026-10-28）

参照: https://ui.tailor.tech/

公開先: https://mailboost.github.io/erpboost-ui/

既存42ケースに16ケースを追加した。PCライト（1280×900）とモバイル幅ダーク（375×812）のChromiumで比較する。全ページ・全入力組み合わせ・全画素の完全一致という意味ではない。

## 見つけて修正した差分

| 対象 | 修正前 | 参照版に合わせた変更 |
| --- | --- | --- |
| 表の右クリック | 見出しにCopy label / Pin column、セルにCopy value等の組み込みメニューが出る。参照版はこれらを出さない | `DataTable.Root`の組み込みメニューを既定で無効にし、ブラウザのcontextmenuイベントを妨げない。`contextMenu`を明示すればコピー・列固定等を利用できる |
| 一括操作の絞り込み | Pendingの2件を選択してApprovedへ変更すると、非表示になった2件の選択とApprove / Rejectが残る | BulkActionsBarサンプルで絞り込み変更時に選択を解除する。共通のページをまたぐ選択処理は変更していない |
| 選択列の固定・背景 | 固定列を指定していない表でもチェックボックス列だけが固定され、見出しの背景が白くなる | 他の固定列がない場合は選択列も通常の列にする。明示的にデータ列を固定した場合は、その横で選択列も固定する |
| 選択チェックボックス | フォーム用の影・リング・ポインターカーソルがあり、参照版の表用表示と異なる | 表専用の小さいチェックボックス表示へ変更し、影なし・ブラウザのフォーカスアウトラインを維持する。単独のCheckboxコンポーネントの表示は変更していない |

ソース: [DataTable](../packages/ui/src/components/data-table/data-table.tsx)、[メニュー状態](../packages/ui/src/components/data-table/use-cell-context-menu.ts)、[BulkExample](../apps/catalog/src/reference/showcases.tsx)。明示的な組み込みメニューの利用方法は[README](../README.md)を参照。

明示的に有効にするメニューは、[コンポーネントテスト](../tests/data-table-context-menu.test.tsx)でコピー、列固定、メニューを無効化した際の状態破棄、再有効化時に古いメニューが復活しないこと、データ列の固定・解除に連動する選択列の状態を確認する。これらはjsdomでの状態・イベント検証であり、実ブラウザでの固定列のスクロール計測とは区別する。

## 画面比較と限界

Pendingの選択からApprovedへ絞り込んだ状態を撮影し、見出し3セルの文字・位置・寸法・フォント・背景・positionが参照と一致した。選択列の影を直した後の画像には、外枠付近に13画素の差が残っている。この状態の比較を全画素一致の証拠にはしない。

公開サンプルには、汎用の`DataTable.Filters`・`ColumnSettings`・列ソートを実際に操作する構成がない。ソースのAPIが存在することと、公開サンプルで操作できたことを区別し、それらの全機能を検証済みとは数えない。比較のためだけに参照版へないUIを追加していない。

スマートフォン実機、iOSの長押しメニュー、他ブラウザ、IME変換中の操作、実サービスへの承認・登録・保存処理も確認対象ではない。

## 公開版で一度発生した未解決の選択解除

最初の公開版全件検証は57件成功・1件失敗だった。失敗したのは既存のモバイル幅ダーク「ページをまたぐ選択」で、1ページ目の1件を選択→2ページ目を全選択・全解除→1ページ目へ戻る操作。保存したトレースのDOMでは、戻った直後の`PO-2026-1001`は選択済みだったが、次のPlaywright操作がない間に未選択へ変わり、確認が失敗した。

同じ既存テストを参照・ローカル・公開で各5回、計15回再実行して全件成功した。公開版でイベント・DOM変更を記録しながら、最初の行への復帰確認までの操作を追加50回行っても再現しなかった。この50回はApprove / Rejectを含むテスト全体の成功件数には加えない。その後の公開版全58ケースも成功した。

**原因は未特定であり、修正済み・単なる待ち時間不足とは判定しない。** この失敗を隠すためのリトライ、待ち時間の追加、検証の削除は行っていない。元の失敗結果・トレース・画面、トレースから復元したチェック状態、追加実行結果を上記証跡フォルダへ保存した。次回の再現時に追跡する未解決事項として残す。
